# 音乐日历模块设计文档

> 版本：v1.0 | 日期：2026-07-04 | 状态：设计中

---

## 一、产品定位

音乐日历是 Claudio 主页的核心模块之一，承载两个维度的时间记忆：

- **个人维度**——我的听歌日记，记录每天的音乐足迹
- **历史维度**——历史上的今天，连接个人与音乐史

核心情感：**仪式感 + 发现感**。让用户每次打开日历都能感受到"音乐陪伴了我的时间"。

### 2.2 交互流程

1. **进入页面**：默认选中今天，展示今天的详情
2. **点击某天**：高亮该日期，下方详情区平滑切换到该天内容
3. **左右滑动/按钮**：切换月份
4. **点击"今天"按钮**：快速回到当月当天
5. **无听歌记录的日期**：只展示"历史上的今天"，"我的今天"板块隐藏
6. **无历史事件的日期**：只展示"我的今天"，"历史上的今天"板块隐藏
7. **两者都无**：展示一个空状态插画 + 文案"这一天很安静"

## 三、视觉设计

### 3.1 设计语言

延续 Claudio 整体风格：深色背景、极简、高级感、微妙动画。

| 元素 | 样式 |
|------|------|
| 页面背景 | `#121212`（与 MusicHall 一致） |
| 日历卡片背景 | `#181818` |
| 今日高亮 | 边框 `#1ed760`，带微弱呼吸光晕 |
| 有记录的日期 | 底部小圆点，颜色从当天歌曲封面提取 |
| 选中日期 | 背景 `#282828`，边框 `#1ed760` |
| 无记录日期 | 正常文字，无特殊标记 |

### 3.2 月历网格设计

- 每个日期格子：**正方形**，内含日期数字
- 有听歌记录的格子：底部中心一个小圆点（4px），颜色为当天听的第一首歌的封面主色调
- 今天：绿色边框 + 微弱呼吸动画（`box-shadow` 脉冲）
- 选中态：背景变亮，边框绿色
- 非当月日期：文字 `#555`，不可点击

### 3.3 "我的今天"卡片

- 左上角小标签：`🎵 我的今天`
- 统计行：`听了 12 首歌 · 1 小时 32 分`
- 封面横列：展示当天前 5 首歌封面（40px 圆角方形），超出显示 `+N`
- 心情标签：从歌曲风格/情绪自动推导，展示 2-3 个标签

### 3.4 "历史上的今天"卡片

- 左上角小标签：`📜 历史上的今天`
- 时间线布局：
  - 年份：大字号（20px），`#555`，右对齐固定宽度
  - 分隔线：竖线 + 小圆点
  - 事件描述：正文（14px），`#b3b3b3`
  - 艺人名：可选，`#1ed760`

### 3.5 动画

| 场景 | 动画 |
|------|------|
| 进入页面 | 日历格子依次淡入（stagger 20ms） |
| 切换选中日期 | 详情区 crossfade（0.3s） |
| 切换月份 | 日历整体滑出/滑入（0.3s ease-out） |
| 今日呼吸光晕 | `box-shadow` 循环脉冲（3s infinite） |
| 封面加载 | 模糊 → 清晰（blur transition） |

## 四、数据模型

### 4.1 播放记录表（MySQL）

```prisma
model PlayRecord {
  id        String   @id @default(cuid())
  userId    String
  songId    String
  playedAt  DateTime @default(now())
  duration  Int?     // 实际播放时长（秒）

  user      User     @relation(fields: [userId], references: [id])
  song      Song     @relation(fields: [songId], references: [id])

  @@index([userId, playedAt])
}
```

**写入时机**：歌曲播放完成，或播放超过 30 秒时记录。

**查询场景**：

```sql
-- 月视图：某月每天的听歌统计
SELECT DATE(playedAt) as date, COUNT(*) as songCount, SUM(duration) as totalDuration
FROM PlayRecord
WHERE userId = ? AND playedAt >= '2026-07-01' AND playedAt < '2026-08-01'
GROUP BY DATE(playedAt)

-- 日详情：某天的完整播放列表
SELECT pr.*, s.title, s.artist, s.coverUrl
FROM PlayRecord pr JOIN Song s ON pr.songId = s.id
WHERE userId = ? AND DATE(pr.playedAt) = '2026-07-04'
ORDER BY pr.playedAt
```

### 4.2 历史事件数据（本地 JSON）

文件路径：`src/data/music-history.json`

```json
{
  "07-04": [
    {
      "year": 1969,
      "event": "The Rolling Stones 在海德公园举办免费演唱会，纪念去世的布莱恩·琼斯",
      "artist": "The Rolling Stones"
    },
    {
      "year": 2002,
      "event": "Eminem 的专辑《The Eminem Show》连续第四周蝉联 Billboard 200 冠军",
      "artist": "Eminem"
    },
    {
      "year": 2015,
      "event": "Apple Music 正式上线，开启流媒体音乐新纪元",
      "artist": null
    }
  ],
  "07-05": [...]
}
```

**数据量规划**：
- 初版覆盖 365 天，每天 2-4 条事件
- 总计约 1000-1200 条
- 每条事件包含：`year`（年份）、`event`（事件描述）、`artist`（相关艺人，可选）
- 优先收录：经典专辑发行、音乐人生卒、重大行业事件、标志性演出

## 五、API 设计

### 5.1 写入播放记录

```
POST /api/calendar/record
Body: { songId: string, duration?: number }
```

### 5.2 获取月度统计

```
GET /api/calendar/monthly?year=2026&month=7
Response: {
  records: [
    { date: "2026-07-01", songCount: 8, totalDuration: 2400, coverColors: ["#xxx", "#yyy"] },
    { date: "2026-07-02", songCount: 3, totalDuration: 900, coverColors: ["#zzz"] },
    ...
  ]
}
```

### 5.3 获取某天详情

```
GET /api/calendar/day?date=2026-07-04
Response: {
  songs: [
    { id, title, artist, coverUrl, playedAt, duration },
    ...
  ],
  totalDuration: 5520,
  songCount: 12
}
```

### 5.4 获取历史事件

```
GET /api/calendar/history?month=7&day=4
Response: {
  events: [
    { year: 1969, event: "...", artist: "The Rolling Stones" },
    ...
  ]
}
```

## 七、里程碑（附属功能）

不单独成系统，作为"我的今天"卡片里的惊喜标记：

| 里程碑类型 | 触发条件 | 展示方式 |
|-----------|---------|---------|
| 新歌手发现 | 今天第一次听某位歌手 | 日历格子上一个小星标 ✦ |
| 连续听歌 | 连续 N 天有播放记录 | 详情卡片顶部徽章"🔥 连续 7 天" |
| 单日最长 | 今天的播放时长超过历史最高 | 详情卡片顶部徽章"🏆 新纪录" |
| 收藏里程碑 | 收藏数达到整百 | 详情卡片顶部徽章"❤️ 第 100 首收藏" |
