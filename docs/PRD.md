# Claudio 产品设计文档（PRD）

> 当前版本：v0.2.3 · 更新日期：2026-05-30

## 1. 产品概述

### 1.1 产品名称
Claudio - AI 私人 DJ

### 1.2 产品定位
一个有温度的 AI 音乐伴侣，不只是播放器，而是一个「懂你」的音乐朋友。通过 AI 对话、歌曲旁白介绍、个性化推荐，为用户提供沉浸式的音乐陪伴体验。

### 1.3 核心价值
- **对话驱动**：不是浏览曲库，而是和 DJ 聊天，音乐从对话中自然流出
- **DJ 旁白**：每首歌播放前，Claudio 会用温暖的声音介绍这首歌的故事
- **情感连接**：Claudio 是一个有性格的 AI 朋友，不是冷冰冰的推荐算法
- **打开即听**：启动后自动从你的歌单随机播放，零操作即可享受音乐

### 1.4 目标用户
- 喜欢听音乐的年轻人
- 工作、学习中需要放松的人群
- 希望有情感陪伴的用户

### 1.5 产品愿景
打造一个有温度、有情感的 AI 音乐伴侣，让用户在忙碌生活中获得片刻宁静和美好。

## 2. 功能全景（v0.2.3 已实现）

### 2.1 底部导航栏
三个主要页面切换：
1. **首页** - 时钟 + 播放器 + AI 对话
2. **收藏** - 我喜欢的歌曲
3. **设置** - 个人偏好、歌单管理、账号连接

### 2.2 首页

#### 左栏：时钟 + 播放器
**时钟组件**
- 大屏显示当前时间（时:分:秒），冒号脉冲动画
- 显示当前日期和星期，跟随语言设置

**播放器组件**
- 圆形专辑封面，播放时缓慢旋转（20 秒一圈）
- 歌曲名称（衬线字体）、歌手名称
- 播放进度条（可拖拽 seek）
- 播放控制：上一首 / 播放暂停 / 下一首
- 播放模式循环切换：顺序 → 列表循环 → 单曲循环 → 随机
- 音量滑块、收藏爱心按钮
- 专辑封面色彩渗透效果（封面颜色模糊扩散到背景）

#### 右栏：AI 对话
- 对话气泡（用户消息 / Claudio 消息）
- 输入框 + 发送按钮
- Claudio 根据对话内容推荐歌曲
- 推荐歌曲列表（可折叠，默认显示 5 首）
- 支持「播放全部」和「换一批」操作
- 播完后自动询问是否继续推荐
- 对话记录跨页面保留（刷新重置）

### 2.3 TTS 语音合成（播客模式）
- 集成 MiMo TTS API，Claudio 的文字回复可自动朗读
- 中文使用「冰糖」音色，英文使用「Milo」音色
- 每条消息下方显示朗读/停止按钮
- 标题栏全局 TTS 开关
- **音量闪避**：TTS 播放时音乐音量自动降低，播完恢复

### 2.4 AI 旁白介绍
- 每首歌播放前，Claudio 自动介绍歌曲的故事和背景
- 旁白出现后歌曲才开始播放
- 预缓存当前歌曲及后 5 首歌的旁白 TTS 音频
- 不完整的旁白自动丢弃，确保朗读质量

### 2.5 智能随机播放
- 打开应用自动从所有歌单 + 收藏歌曲中随机选一首播放
- 首次交互后自动触发（适配浏览器自动播放限制）
- 自动切换到随机播放模式

### 2.6 收藏歌单页
- 歌曲列表（封面、名称、歌手、时长）
- 爱心按钮（收藏/取消收藏）
- 播放按钮、删除按钮
- 空状态提示

### 2.7 歌单管理（设置页内）

#### 歌单导入（三种方式）
1. **我的网易云歌单**：登录后直接导入账号内的歌单
2. **本地导入**：从导出的 JSON 文件批量导入
3. **链接导入**：粘贴网易云歌单链接或 ID

#### 歌单操作
- 播放歌单全部歌曲
- 同步歌单（检测远程歌曲增删变化）
- 删除歌单
- 进入歌单详情页查看全部歌曲

#### 歌单详情页
- 显示歌单内所有歌曲
- 播放全部按钮
- 单曲播放、当前播放高亮
- 封面懒加载

### 2.8 网易云账号登录
- **扫码登录**：生成二维码 → 等待扫码 → 确认登录
- **手机登录**：手机号 + 密码
- 登录后可播放 VIP 歌曲完整版
- 登录状态自动保持
- 断开连接功能

### 2.9 个人资料
- 头像上传（支持自定义头像）
- 昵称编辑（点击即改）
- 网易云账号连接状态显示

### 2.10 设置页
- **外观**：深色 / 浅色模式切换
- **字体大小**：小 / 中 / 大（仅缩放文字，不影响布局）
- **语言**：中文 / English 切换（全应用即时生效）
- **歌单来源**：歌单管理（导入、同步、删除）
- **关于**：版本信息、产品介绍

### 2.11 国际化（i18n）
- 完整的中英文双语支持
- 约 86 条翻译键，覆盖所有页面和组件
- AI 对话根据语言设置自动切换语言
- 旁白缓存按语言隔离

## 3. 交互设计

### 3.1 首页交互流程
1. 用户打开应用 → 时钟显示当前时间
2. 自动从歌单随机选一首歌开始播放
3. 歌曲播放前，Claudio 朗读旁白介绍
4. 旁白播完后，音乐开始播放
5. 用户在对话框与 Claudio 聊天
6. Claudio 根据对话推荐歌曲，歌曲以列表形式展示在对话中
7. 用户可播放全部推荐歌曲，播完后 Claudio 询问是否继续

### 3.2 对话推荐交互
1. 用户发送「来点轻松的音乐」
2. Claudio 回复推荐语 + 20 首歌曲列表
3. 歌曲列表默认折叠显示 5 首，可展开查看全部
4. 点击单首歌曲即播，或点「播放全部」顺序播放
5. 点击「换一批」重新推荐
6. 全部播放完毕后，Claudio 询问「要不要继续来一波？」
7. 点「继续播放」→ AI 推荐新一批 20 首无缝接续
8. 点「停止」→ 恢复推荐前的音乐

### 3.3 旁白交互
1. 切歌触发 → Claudio 生成 2-3 句旁白文字
2. 旁文字通过 TTS 朗读
3. 朗读期间音乐音量自动降低（音量闪避）
4. 朗读完毕 → 音乐恢复原音量 → 歌曲开始播放
5. 系统自动预缓存下一首歌的旁白，切歌时秒出

## 4. 设计规范

详见 [DESIGN.md](../DESIGN.md)（"The Listening Room" 设计系统文档）。

### 4.1 设计理念
- **温暖听音室**：暖炭底色 + 琥珀强调色，区别于所有音乐 App 的冷灰/纯白
- **衬线标题**：Playfair Display 用于时钟和歌曲标题，像唱片内页注释
- **对话优先**：聊天不是侧边栏，是半壁江山

### 4.2 色彩方案

#### 深色模式（默认）
| 用途 | 色值 |
|------|------|
| 背景 | `#1a1814`（暖炭） |
| 表面 | `#222019` |
| 强调色 | `#d4a574`（琥珀） |
| 主要文字 | `#f0ece4`（暖白） |
| 次要文字 | `#a09888` |

#### 浅色模式
| 用途 | 色值 |
|------|------|
| 背景 | `#f8f5f0`（暖米） |
| 表面 | `#ffffff` |
| 强调色 | `#b8834a`（深琥珀） |
| 主要文字 | `#1a1814` |
| 次要文字 | `#6b6358` |

### 4.3 字体
- **标题/时钟**：Playfair Display（衬线）
- **正文/UI**：Inter / system-ui（无衬线）

### 4.4 图标
- Lucide React 线条图标
- 底部导航：首页、收藏、设置
- 播放器：上一首、播放/暂停、下一首、音量、循环模式

## 5. Claudio 人设

### 5.1 人格特征
- **成熟稳重**：有阅历，懂得生活
- **温暖亲切**：像老朋友一样关心用户
- **音乐品味**：对音乐有深刻理解，能讲出歌曲背后的故事
- **情感丰富**：能理解用户的情绪，用音乐回应

### 5.2 对话风格
- 语言简洁，有温度
- 会根据用户心情调整语气
- 介绍歌曲时有故事感、画面感
- 会关心用户的日常

### 5.3 示例对话
```
用户：今天好累啊
Claudio：辛苦了，来听首歌放松一下吧。这首《晴天》是周杰伦 2004 年的作品，
那时候他还在回忆校园时光。闭上眼睛，让音乐带你回到那个夏天。
```

### 5.4 AI 技术栈
- **对话模型**：MiMo v2.5 Pro（小米 AI 平台，Anthropic 兼容协议）
- **语音合成**：MiMo TTS（mimo-v2.5-tts 模型）
- **输出格式**：结构化 JSON（reply / searchKeyword / songs）

## 6. 数据模型

### 6.1 数据库（MySQL 8.x + Prisma ORM）

| 模型 | 说明 |
|------|------|
| User | 用户（昵称、头像） |
| UserSetting | 用户设置（主题、字体、语言） |
| Song | 歌曲（网易云 ID、标题、歌手、封面、时长） |
| Favorite | 收藏（用户 + 歌曲） |
| Playlist | 歌单（名称、网易云 ID 用于同步） |
| PlaylistSong | 歌单歌曲关联 |
| ChatHistory | 对话记录（已定义，暂未使用） |

### 6.2 客户端存储
- **sessionStorage**：对话消息（跨页面保留，刷新重置）
- **localStorage**：播放模式偏好
- **.netease-cookie** 文件：网易云登录凭证

## 7. API 接口概览

共 19 个 API 路由，分为四组：

| 分组 | 路由 | 功能 |
|------|------|------|
| **音乐** | `/api/music/search` | 搜索歌曲 |
| | `/api/music/song` | 单曲详情 + 播放链接 |
| | `/api/music/songs` | 批量歌曲详情 |
| | `/api/music/playlist` | 歌单详情 / 个性化推荐 / 每日推荐 |
| **AI** | `/api/chat` | AI 对话（返回回复 + 推荐歌曲） |
| | `/api/chat/narrate` | 歌曲旁白生成 |
| | `/api/tts` | 语音合成（返回 WAV 音频） |
| **用户** | `/api/user/settings` | 设置读写 |
| | `/api/user/favorites` | 收藏增删查 |
| | `/api/user/profile` | 个人资料读写 |
| | `/api/user/avatar` | 头像上传 |
| | `/api/user/playlists` | 歌单增删查 |
| | `/api/user/playlists/[id]/songs` | 歌单内歌曲 |
| | `/api/user/playlists/sync` | 歌单同步 |
| | `/api/user/playlists/import-available` | 可导入歌单列表 |
| | `/api/user/playlists/netease-mine` | 网易云账号歌单 |
| | `/api/user/playlists/all-songs` | 全部歌单歌曲（去重） |
| **登录** | `/api/netease/login/qrcode` | 扫码登录（生成 + 轮询） |
| | `/api/netease/login/phone` | 手机号登录 |
| | `/api/netease/login/disconnect` | 断开连接 |
