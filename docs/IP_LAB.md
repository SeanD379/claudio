# Claudio IP Lab · 0–30 天执行包

## 目的与边界

- 目的：用三个独立 IP 概念验证小红书获客与 Claudio 首播/保存歌单转化。
- 人群：18–28 岁独居青年。
- 边界：本阶段不接入推荐、登录、播放与数据库；不删除现有 `Pet`，避免未验证即改变产品认知。
- 工作名：声栖 Soni、舞台猫 Clau、拾音兔 Mero 均未做商标、账号或域名检索，不得以“已可注册”对外发布。

## 小红书样片脚本

每条为 6–15 秒，首帧只出现一个可代入场景；结尾统一落到“打开 Claudio，生成你的卡”。歌曲须使用已获授权的音频、平台曲库或无版权音频。

### 声栖 Soni

1. `今晚不想和任何人说话时`：0–2 秒为关灯后的空房间；2–7 秒声栖声核亮起并出现一句“先听完这一首”；7–12 秒出现情绪卡与 CTA。
2. `独居人的 23:47 声音日记`：时钟 23:47；切到声栖收进一段声波；显示“今天不用总结，只留一首歌”。
3. `把今天装进黑胶`：三个日常镜头（地铁、晚餐、窗外）；声栖将它们压成一张虚拟黑胶；展示可保存卡片。

### 舞台猫 Clau

1. `社恐进 KTV 前 vs 点到第一首歌后`：前半低头握麦，副歌时切到金色追光；末帧“你的舞台色盘”。
2. `如果情绪也有返场`：一句“今天的遗憾，要不要再唱一次”；角色从暗处走进舞台；结尾引导一句唱完挑战。
3. `把客厅唱成万人场`：普通客厅/耳机；灯光和歌词节拍叠入；末帧“打开 Claudio KTV”。

### 拾音兔 Mero

1. `给今天的自己留一段 8 秒声音`：雨声或锅碗声；Mero 放入拾音包；出现“照片 + 一首歌 = 今日声音便签”。
2. `一人食的听歌桌搭`：餐桌细节与一张歌单卡；Mero 贴好便签；CTA 为保存这顿饭的歌。
3. `把评论区的情绪做成小卡`：挑选一条匿名评论；Mero 制作卡片；引导用户留言“今天像哪一首歌”。

## 测试与决策表

| 阶段 | 统一动作 | 记录指标 | 决策门槛 |
| --- | --- | --- | --- |
| 0–30 天 | 用 `/ip-lab` 展示三案；准备同规格素材和落地链接 | 概念卡点击、文案复制、角色偏好 | 不基于主观喜好选角色 |
| 31–60 天 | 每案 8–12 条、相近发布时间与标签量 | 3 秒留存、收藏率、有效评论率、落地页点击、注册 | 以注册转化优先，其次是收藏率和有效评论率 |
| 61–90 天 | 仅使用胜出角色做产品轻接入与一个低成本预售品 | 首日播放/保存歌单、7 日留存、预售转化 | 未达预设基线不扩展盲盒或大体量生产 |

每条内容只使用一个角色、一个情绪场景、一个行动入口。不要混用三个角色，也不要在角色尚未胜出时将其放入 Claudio 的正式首页、聊天、推荐或 KTV 流程。
