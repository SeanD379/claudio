## 三、核心功能模块

### 3.1 AI 对话系统 ⭐

**实现方式**：调用 MIMO API（兼容 Anthropic 协议）

**核心特性**：
- 支持中英文双语对话
- AI 自动识别用户意图：点歌、推荐、闲聊
- 返回结构化 JSON：`{reply, searchKeyword, songs}`
- 支持批量推荐（一次性 20 首）
- 无版权歌曲自动推荐替代方案（10 首）

**System Prompt 设计亮点**：
- 定义了 Claudio 的人格特征：成熟稳重、温暖亲切
- 强制 JSON 格式输出，便于前端解析
- 明确的规则处理不同场景

### 3.2 音乐播放器

**状态管理**：Zustand store (`usePlayer.ts`)

**播放模式**：
- 顺序播放（Sequential）
- 随机播放（Shuffle）- Fisher-Yates 洗牌算法
- 单曲循环（Repeat One）
- 全部循环（Repeat All）

**特色功能**：
- 打开即听（首次交互自动播放）
- 播完续播（AI 自动推荐下一批歌曲）
- 进度条拖拽
- 音量控制

### 3.3 AI 旁白系统

**实现**：`useNarration` hook + `narrate` API

**工作流程**：
1. 歌曲播放前，AI 生成 2-3 句旁白介绍
2. 旁白显示后才开始播放音乐
3. 自动预缓存接下来 5 首歌的旁白
4. 按语言隔离缓存

### 3.4 歌单导入系统

**三种导入方式**：
1. **我的歌单**：从已登录的网易云账号导入
2. **本地导入**：从本地文件批量导入
3. **链接导入**：通过歌单链接/ID 导入任意歌单

**同步功能**：自动检测歌曲增删变化

### 3.5 国际化 (i18n)

**实现方式**：自定义 `useTranslation` hook

**覆盖范围**：约 90 条文本实现中英文翻译

**AI 对话语言自适应**：
- 中文模式：Claudio 使用中文回复
- 英文模式：无论用户输入什么语言，Claudio 始终英文回复
