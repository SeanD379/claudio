


# 更新日志

## v0.2.4 (2026-06-25)

### 新增功能

- **首页弧形歌曲列表（CircularPlaylist）**
  - 首页听歌模式右侧新增弧形歌曲列表，鼠标靠近右边缘自动滑出，离开后自动收回
  - 歌曲卡片沿抛物线弧度排列，中间偏左、上下偏右，形成对称浅弧视觉效果
  - 每张卡片显示：序号、封面缩略图、歌曲名称、歌手名字
  - 当前播放歌曲高亮显示（紫色边框 + 发光效果 + 动态音乐条）
  - 滚轮上下滚动浏览全部歌曲，第一首/最后一首停在中间位置，不会滑出边界
  - 右侧竖排"回到当前"按钮，点击后平滑动画（easeOutCubic 400ms）归位到当前歌曲
  - 歌曲切换时自动重置滚动位置到当前歌曲

### 技术实现

- 新建 `src/app/components/home/CircularPlaylist.tsx`
  - 基于 framer-motion 的弹簧动画滑入/滑出
  - 抛物线弧度计算：`x = cardBaseX + t² × arcBulge`
  - 透明背景，仅卡片保留毛玻璃效果，与主页动态丝绸背景自然融合
  - 滚动边界限制：可见窗口不超出播放列表首尾
  - 平滑滚动动画：requestAnimationFrame + easeOutCubic 缓动
- 修改 `src/app/page.tsx` — 集成 CircularPlaylist 组件到听歌模式区域

## v0.2.3 (2026-05-30)

### 新增功能

- **TTS 语音合成（播客模式）**
  - 集成 MiMo TTS API，Claudio 的文字回复自动朗读
  - 根据用户语言自动切换音色：中文使用"AD学姐"，英文使用"Milo"
  - 每条消息下方显示朗读/停止按钮，支持手动控制
  - 标题栏右侧新增全局 TTS 开关按钮
  - TTS 播放时音乐音量自动降低（音量闪避），播完后恢复

- **旁白语音朗读**
  - 旁白文字生成后自动调用 TTS 朗读
  - 旁白朗读完成后才播放音乐，不会错过精彩介绍
  - 预缓存当前歌曲及后 5 首歌的旁白 TTS 音频，切歌时秒出
  - 不完整的旁白自动丢弃，确保朗读质量

- **智能随机播放**
  - 未指定歌单播放时，自动随机播放所有已添加歌单的歌曲
  - 同时包含"我喜欢的歌曲"里的收藏歌曲
  - 自动切换到随机播放模式

### 优化改进

- **播放模式按钮整合**
  - 将顺序播放、随机播放、单曲循环整合为一个按钮
  - 点击循环切换：顺序播放 → 列表循环 → 单曲循环 → 随机播放
  - 每种模式显示对应图标，更直观

- **播放器优化**
  - 修复歌曲封面图片获取失败的问题
  - 修复播放进度条中歌曲时长显示为 0 的问题
  - 切歌时暂停当前音乐，等待旁白播完后再播放新歌

- **对话框优化**
  - 对话框大小固定，消息过多时在右侧显示滚动条
  - 页面切换时保留对话记录，刷新页面才重置

- **设置页优化**
  - 已添加歌单列表添加滚动条，支持显示更多歌单
  - 超过 5 个歌单时自动出现滚动条

### 问题修复

- 修复 TTS 播放按钮状态同步问题，只有当前播放的消息显示停止按钮
- 修复切歌时进度条异常显示的问题
- 修复页面切换时对话记录被清除的问题

## v0.2.2 (2026-05-28)

### 新增功能

- **完整的中英文语言切换**
  - 设置页切换语言后，整个应用界面立即变为对应语言
  - 涵盖所有页面：首页、收藏、设置、歌单详情、导入歌单弹窗
  - 包括导航栏、播放器、时钟、聊天、个人资料、Toast 提示等全部组件
  - 约 90 条文本实现中英文翻译
  - 语言设置持久化保存，刷新页面后仍然生效

- **AI 对话语言自适应**
  - 中文模式下，Claudio 使用中文进行对话和歌曲旁白介绍
  - 英文模式下，Claudio 使用英文进行对话和歌曲旁白介绍，且无论用户输入中文还是英文，Claudio 始终以英文回复
  - 旁白缓存按语言隔离，切换语言后不会出现旧语言缓存

- **AI 智能推荐歌单**
  - 用户请求推荐类歌曲时（如"来点轻松的音乐"），Claudio 一次性推荐 20 首歌曲
  - 对话框内展示可折叠歌曲列表，默认显示 5 首，展开后内部滚动
  - 每首歌曲右侧有播放按钮，点击即播
  - 支持"播放全部"和"换一批"操作
  - 用户点播具体歌曲无版税时，自动推荐 10 首替代歌曲

- **播完续播体验**
  - 播放全部歌曲播完后，Claudio 自动询问是否继续播放类似歌曲
  - 点击"继续播放"：AI 推荐新一批 20 首歌曲并无缝接续播放
  - 点击"停止"：恢复播放推荐前的音乐

### 问题修复

- 修复扫码登录后无法立即获取用户信息并刷新出成功登录页面的问题
  - 原因：网易云 API 登录生效存在延迟，首次获取 profile 可能为空
  - 方案：扫码成功后自动重试获取 profile（最多 5 次，每次间隔 1 秒）
- 修复刷新网页后对话记录未清除的问题（移除 sessionStorage 持久化）
- 修复页面整体出现滚动条的问题，改为仅对话消息区域内部滚动
- 修复字体大小设置影响网页框架布局的问题，改为仅缩放文字

## v0.2.1 (2025-05-23)

### 新增功能

- **AI 旁白介绍**
  - 每首歌播放前，Claudio 会先为你介绍这首歌的故事和背景
  - 旁白出现后歌曲才开始播放，不会错过精彩介绍
  - 自动提前缓存接下来 5 首歌的旁白，切歌时秒出

- **打开即听**
  - 打开 Claudio 自动从你的歌单里随机选一首歌播放
  - 页面切换不会中断正在播放的音乐

- **播放模式**
  - 新增播放模式切换按钮：顺序播放、随机播放、单曲循环
  - 点击随机按钮随机打乱播放顺序
  - 点击循环按钮切换：全部循环 → 单曲循环 → 关闭循环
  - 记住你上次选择的播放模式

- **对话记录保留**
  - 切换页面时对话内容自动保存，不会丢失
  - 刷新页面才会重置对话

### 问题修复

- 修复打开页面时时钟显示闪烁的问题
- 修复导入歌单播放第一首歌时没有旁白的问题
- 修复打开页面时自动播放被浏览器拦截的问题
- 修复旁白介绍不出现的问题

## v0.2.0 (2025-05-23)

### 新增功能

- **歌单导入系统**
  - 支持从网易云音乐账号导入个人歌单
  - 支持通过歌单链接导入任意歌单
  - 支持从本地导出文件批量导入
  - 导入弹窗新增三标签页：我的歌单、本地导入、链接导入

- **歌单管理**
  - 歌单列表展示歌曲数量、同步状态
  - 支持播放、同步、删除歌单操作
  - 同步功能自动检测歌曲增删变化

- **歌单详情页**
  - 点击歌单进入详情页查看全部歌曲
  - 显示歌曲封面、时长、专辑信息
  - 支持播放全部、单曲播放
  - 当前播放歌曲动画高亮

- **网易云账号登录**
  - 支持扫码登录网易云音乐 API
  - 登录后可播放 VIP 歌曲完整版
  - 登录状态自动保持，重启后恢复

- **个人资料**
  - 设置页新增个人资料卡片
  - 显示网易云头像和昵称
  - 支持上传自定义头像
  - 昵称可点击编辑

### 技术优化

- 歌曲封面从网易云 API 动态获取
- 登录 Cookie 持久化存储
- API 请求自动携带登录凭证
